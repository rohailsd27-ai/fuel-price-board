About these numbers

  • Prices are pulled automatically from public price-tracking sources a few times a day. See each row's small print for where its numbers came from.
  • Currency conversions use a live USD exchange rate, refreshed on the same schedule as the prices.
  • If you see a price marked "last known value," it means the automated check couldn't reach that source this time — the number shown is the most recent one that did work, not a live figure.

How the automatic updates work

  • A small script (scrape.py) runs on a schedule (GitHub Actions, free), checks each country's price source, and writes the results into data.json.
  • This page just reads data.json — there's nothing to edit here day to day.
  • If a source website changes its layout and the script stops finding a number, the page will show a warning banner (like the one above) instead of a wrong price, and the last good value stays on screen until it's fixed.
  • You can still hand-edit data.json at any time if you want to correct or add something manually — the site will pick it up on next load.
